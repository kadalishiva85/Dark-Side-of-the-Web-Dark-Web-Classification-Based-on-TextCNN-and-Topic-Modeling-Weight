# Dark-Side-of-the-Web-Dark-Web-Classification-Based-on-TextCNN-and-Topic-Modeling-Weight

The dark web is a hidden part of the internet that requires special software like Tor to access and is often used for anonymous communication and activities. This project focuses on improving Dark Web classification related to cyber threats by addressing the inefficiencies of traditional text processing methods. Instead of using all text data, the research selectively extracts keywords using topic modeling to reduce vector dimensions and enhance learning efficiency. By integrating topic modeling with TextCNN, the proposed approach achieves more accurate classification. The model’s performance was validated on two datasets and outperformed existing text classification methods.
